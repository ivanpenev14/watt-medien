# Watt?! Medien

Zwischenablage für den YouTube-Kanal Watt?!: Videos und Thumbnails liegen hier nur kurz,
bis Metricool sie für die geplante Veröffentlichung abgeholt hat, und werden danach wieder entfernt.

## Linkseite watt-lernen.com

Der Ordner `docs/` ist die öffentliche Linkseite von Watt?! (GitHub Pages, Quelle: Branch `main`, Ordner `/docs`, Domain in `docs/CNAME`).
Hilfe, Impressum und Datenschutz liegen auf derselben Seite (`/#hilfe`, `/#impressum`, `/#datenschutz`); `/hilfe/`, `/impressum/` und `/datenschutz/` leiten dorthin weiter.
